# RTL Page Builder

A block-based page builder MVP for Persian (RTL) websites and landing pages.

## Current Features

- Block Registry Architecture
- Heading Block
- Paragraph Block
- Zustand Store
- Block Selection
- Block Editing
- RTL-first UI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Zustand
- dnd-kit

## Roadmap

- LocalStorage Persistence
- Add Block Flow
- Delete Block
- Drag & Drop Reordering
- Preview Page
- Additional Blocks

Work in Progress (MVP)
